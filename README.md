По графику видно, что для небольших деревьев с низкой высотой (1–5) время построения рекурсивной и нерекурсивной реализации практически одинаковое и обе функции работают быстро. При средних высотах (6–10) рекурсивная реализация начинает занимать больше времени из-за экспоненциального роста числа рекурсивных вызовов, тогда как нерекурсивная версия остаётся стабильной с небольшой задержкой на обработку очереди. Для высоких деревьев (более 10) время построения рекурсивной функции заметно возрастает, и при очень больших высотах возможны ошибки переполнения стека, в то время как нерекурсивная реализация корректно строит дерево даже при больших размерах. В целом, для небольших деревьев удобно использовать рекурсию, а для больших деревьев и задач, где важна устойчивость и экономия стека, предпочтительнее нерекурсивный подход.
